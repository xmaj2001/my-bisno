# Bisno - Plataforma Angolana de Afiliados

> Divulga produtos. Ganha comissões. A plataforma que conecta afiliados, clientes e lojas em Angola de forma simples e direta pelo WhatsApp.

![Bisno Hero Preview](.preview/screenshot.png)

---

## Sobre o Projeto

A **Bisno** é a primeira plataforma angolana de marketing de afiliados focada no comércio local. A nossa proposta elimina a burocracia do e-commerce tradicional: o afiliado escolhe produtos, obtém um cupom exclusivo e partilha o link diretamente para o WhatsApp das lojas parceiras.

---

## Como Funciona (O Fluxo em 4 Passos)

```
 [ Afiliado ] 
 (Escolhe produto & copia cupom)
 [ Cliente ] 
 (Clica no link WhatsApp) ──> [ Loja ] ──(Trata da venda & entrega)
```

1. **Escolhe produtos:** Navega pelo catálogo e adiciona os produtos ao teu estoque virtual.
2. **Recebe o teu cupom:** Cada item adicionado gera automaticamente um **cupom exclusivo** (ex: `ANA27`).
3. **Conhece a comissão:** Consulta previamente a percentagem de comissão (ex: 2%, 5%, 10%) de cada venda.
4. **Divulga onde quiseres:** Partilha textos prontos no WhatsApp, Facebook, Instagram, TikTok, Grupos e Estados.

---

## 🔄 Fluxo de Envio e Compra (Três Pontos de Vista)

| 👤 Afiliado | 👥 Cliente | 🏬 Loja |
| :--- | :--- | :--- |
| **1.** Abre o produto no estoque | **4.** Clica no link recebido | **7.** Recebe a mensagem com produto + cupom |
| **2.** Copia o texto pré-formatado | **5.** O WhatsApp abre direto na loja | **8.** Identifica a origem e fecha a venda |
| **3.** Envia para contactos/grupos | **6.** Envia a mensagem com o cupom | **9.** Atribui a comissão ao afiliado |

## ⚡ Principais Vantagens

### Para o Afiliado
- 📦 **Sem gestão de stock:** Não precisas de comprar nem guardar produtos.
- 💳 **Sem cobranças:** A loja trata de receber os pagamentos.
- 🚚 **Sem entregas:** A logística é 100% responsabilidade da loja.

### Para o Cliente
- 🔓 **Sem necessidade de registo:** Não precisa criar conta na plataforma.
- 📱 **Sem apps adicionais:** Não precisa de instalar nada, utiliza apenas o WhatsApp.
- 💬 **Contacto direto:** Conversa simples e imediata com o vendedor.

## 🚀 Como Executar o Projeto Localmente

### Pré-requisitos
* Node.js (versão 18+ recomendada)
* Gerenciador de pacotes (`npm`, `pnpm` ou `yarn`)

### Passos

1. **Clonar o repositório:**
   ```bash
   git clone https://github.com/seu-usuario/bisno.git
   cd bisno
   ```

2. **Instalar as dependências:**
   ```bash
   npm install
   ```

3. **Iniciar o servidor de desenvolvimento:**
   ```bash
   npm run dev
   ```

4. Acesse no navegador: `http://localhost:3000`

## ❓ Perguntas Frequentes (FAQ)

<details>
<summary><b>1. Quanto custa ser afiliado?</b></summary>
Ser afiliado na Bisno é totalmente gratuito. Não há mensalidades nem taxas de inscrição.
</details>

<details>
<summary><b>2. Quanto vou ganhar?</b></summary>

O link pré-formatado gerado pela Bisno insere automaticamente o teu cupom exclusivo na mensagem inicial que o cliente envia à loja via WhatsApp.
</details>

<details>
<summary><b>4. O cliente precisa de criar conta?</b></summary>
Não. O cliente interage diretamente com o WhatsApp da loja parceira.
</details>
